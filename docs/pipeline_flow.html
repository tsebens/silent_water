The flow

What the dispatcher does on every run

It is plain shell, not Claude. It runs within seconds of any label change or close on an issue or PR, and every 30 minutes as a backstop. Each run, in order:

  1. Pause check. Exits if the repository variable PIPELINE_PAUSED is true.
  2. Mirror the board. An arc dragged to Ready gets the ready label, but only if none of its blockers is open.
  3. Unblock. A blocked arc whose Blocked by: issues and native dependencies are all closed becomes ready. A missing or malformed blocker line stops the arc with needs-human.
  4. Recover orphans. A claimed arc whose build run died goes back to ready once; a second time it gets needs-human.
  5. Claim. While in-flight arcs are below WORKER_CAP, take the oldest ready arc whose Touches: overlap nothing in flight, mark it claimed and start a development run.
  6. Close finished concepts, and finished milestones once their last sub-issue has been closed for 24 hours.
  7. Project labels onto the board. It is the only writer of board Status: blocked → Backlog, ready → Ready, claimed → In progress, in-review → In review, closed → Done.
  8. Log anomalies: a PR stuck in changes-requested, an arc closed and reopened, an open arc whose PR already merged.

Bounded loops and guardrails

  • Two plan rejections, three review rounds, or three CI failures in a row each end in needs-human, never a fourth attempt.
  • The dispatcher is the only thing that starts builds; ready is a queue marker, not a trigger. The worker cap and the Touches: overlap check are what make parallel arcs safe.
  • Jobs that hold the PAT run only code from dev. A PR is fetched as content, never as instructions, so it cannot rewrite the agent reviewing it.
  • Agents never create labels and never write board Status. Role prompts, workflows and the process doc change only through PRs into dev, and the review agent flags any weakened guardrail.
  • An audit agent reads the pipeline's own runs every six hours and reports on the standing Pipeline health issue; it files findings as unlabelled concepts for Tristan and never acts.
