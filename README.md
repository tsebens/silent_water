## Development

Requires **Godot 4.7.2** (standard build, not .NET). Scripts are typed GDScript.

Run a local crew of N players (1 host + N−1 clients, windows tiled):

```bash
tools/launch.sh 4
```

Run the headless checks (import, unit tests, two-process network smoke test):

```bash
tools/check.sh
```

Set `GODOT=/path/to/godot` if the binary isn't on `PATH` as `godot`.

After re-exporting the sub from Onshape (as a single assembly glTF to `assets/media/sub/Assembly 1.gltf`), rebuild the game model:

```bash
python3 -m pip install numpy trimesh fast-simplification
python3 tools/convert_sub.py
```

Launch arguments go after `--`: `--host`, `--join [address]`, `--port <n>`, `--name <s>`. With no arguments the game opens a dev connect menu.

### Layout

| Path | Contents |
| --- | --- |
| `src/` | Game code and scenes, one folder per system (`sub/` hull, physics and stations; `interact/` controls and seats; `map/` holographic maps; `site/` dive-site terrain; `creature/` the apex; `sonar/`, `noise/`, `net/`, `debug/` …) |
| `assets/sub/` | Game model of the sub, generated by `tools/convert_sub.py` |
| `assets/media/` | Source media (Onshape exports, reference images); not imported by Godot |
| `tests/unit/` | Unit tests (`test_*.gd`, extend `TestCase`) |
| `tests/` | Test runner and network smoke test |
| `tools/` | Launch and check scripts; `compare_autotest.py` checks multi-instance runs; `convert_sub.py` builds the sub model |
| `docs/` | Architecture notes |
