## Development

Requires **Godot 4.7.2** (standard build, not .NET). Scripts are typed GDScript.

Run a local crew of N players (1 host + N−1 clients, windows tiled):

```bash
tools/launch.sh 4
```

Run the headless checks (import, unit tests, network smoke test, three-instance autotest):

```bash
tools/check.sh
```

Set `GODOT=/path/to/godot` if the binary isn't on `PATH` as `godot`.

To pick up or propose work, follow [the development process](docs/process.md) and the [project board](https://github.com/users/tsebens/projects/1).

The committed game model is `assets/sub/sub_hull.glb`, generated from `assets/models/vehicles/sub_interior/program.yaml`. To change the hull, edit the program, then regenerate (see `docs/sub_frame.md`):

```bash
uv run --project tools/asset_pipeline python assets/models/vehicles/sub_interior/plan.py
python3 tools/build_sub_hull.py
```

Launch arguments go after `--`: `--host`, `--join [address]`, `--port <n>`, `--name <s>`. With no arguments the game opens a dev connect menu.

### Layout

| Path | Contents |
| --- | --- |
| `src/` | Game code and scenes, one folder per system (`sub/` hull, physics and stations; `interact/` controls and seats; `map/` holographic maps; `site/` dive-site terrain; `creature/` the apex; `sonar/`, `noise/`, `net/`, `debug/` …) |
| `assets/sub/` | Game model of the sub (the hull), generated by `tools/build_sub_hull.py` |
| `assets/media/` | Source media (reference images); not imported by Godot |
| `tests/unit/` | Unit tests (`test_*.gd`, extend `TestCase`) |
| `tests/` | Test runner and network smoke test |
| `tools/` | Launch and check scripts; `compare_autotest.py` checks multi-instance runs; `build_sub_hull.py` builds the sub hull |
| `docs/` | Architecture notes |
| `.github/agents/` | Pipeline role prompts, one per agent |
| `.github/actions/` | Shared actions: `setup-godot` and `claude-role` (runs one pipeline agent with the Claude Code CLI) |
| `.github/workflows/` | CI, the dispatcher and one `role-*.yml` workflow per pipeline agent |
